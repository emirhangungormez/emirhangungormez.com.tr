How Do I Get Things Done?

I structure my areas of work under five main titles within the framework of architectural design, problem-solving approach, and technical capabilities. These summaries present my production discipline and thinking model rather than tool selection.

01.

Mobile and Desktop Applications

I measure the value of an idea not just by whether it works, but by how effectively it solves a real user problem. I build the technical backbone of products, from lightweight prototypes to scalable applications.

React Native · SwiftUI · Python · Electron · .NET
02.

Web and Security Research

I don't just develop web applications; I research how data is processed, protected, and where system vulnerabilities lie. I treat product development and security as parts of the same architecture.

PHP · JavaScript · React · SQL · Web Security
03.

Cryptology and Blockchain
